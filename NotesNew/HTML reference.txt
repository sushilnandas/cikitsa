CSS Flex

.app-container {
  display: flex;              /* activates flexbox */
  flex-direction: row;        /* side by side */
  justify-content: space-around; /* spacing between components */
  align-items: center;        /* vertical alignment */
  border: 2px solid black;
  background-color: lightgray;
}

display flex → turns the parent into a flex container.

flex-direction → row for horizontal, column for vertical stacking.

justify-content → controls spacing along the main axis.

align-items → controls alignment along the cross axis.




ii).app-container {
  display: grid;              /* activates grid */
  grid-template-columns: 1fr 1fr; /* two equal columns */
  gap: 20px;                  /* spacing between items */
  border: 2px solid black;
  background-color: lightgray;
}


display grid → turns the parent into a grid container.

grid-template-columns → defines how many columns and their sizes.

gap → spacing between rows/columns.

harizontal centering
 position: fixed;
  top: 0;              /* stays at the top */
  left: 50%;           /* anchor at middle of viewport */
  transform: translateX(-50%); /* shift back by half its width */
  width: 80%;          /* optional: shrink so it doesn’t span full width */
}


vertical centering 
.header {
  position: fixed;
  top: 50%;            /* anchor at middle of viewport */
  left: 50%;           /* anchor at middle horizontally */
  transform: translate(-50%, -50%); /* shift back by half width & height */
  width: 400px;        /* set a fixed width */
  height: 100px;       /* set a fixed height */
}
