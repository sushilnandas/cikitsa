----------------------------------------------------------------------------------------

+--------------------------------------------------+
|                STATIC (default)                  |
|  - Follows normal document flow                  |
|  - top/left ignored                              |
+--------------------------------------------------+

+--------------------------------------------------+
|                RELATIVE                          |
|  - Stays in flow, but can be nudged              |
|  - top/left shift element slightly               |
|  - Parent stays same size                        |
+--------------------------------------------------+

+--------------------------------------------------+
|                ABSOLUTE                          |
|  - Removed from flow                             |
|  - Anchored to nearest positioned ancestor       |
|  - If no ancestor, anchors to <html>             |
+--------------------------------------------------+

+--------------------------------------------------+
|                FIXED                             |
|  - Removed from flow                             |
|  - Anchored to viewport (browser window)         |
|  - Stays in place when scrolling                 |
+--------------------------------------------------+

+--------------------------------------------------+
|                STICKY                            |
|  - Acts like relative until scroll threshold     |




Static → default, no special positioning.

Relative → nudges element but keeps flow.

Absolute → anchors to parent if relative.

Fixed → pins to viewport, ignores parent.

Sticky → hybrid: relative until scroll, then fixed.
